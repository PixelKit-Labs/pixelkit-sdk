# Laya decision layer — implementation checkpoint

Delta Mobile 1.0.91 retains local Laya inference as advisory intent and bounded tool-selection guidance inside the durable Turn Coordinator. The canonical implementation chapter is [Delta Mobile's Laya integration](../../../delta-mobile/docs/laya-integration.md); it records model/runtime provenance, setup, lifecycle, privacy, thresholds, and verification limits.

## Implemented source

Delta 1.0.88/code144 source defines the production 32-label taxonomy, conditional named-Skill verifier, and labeled corpus in `src/core/toolIntentGuidance.ts`. The primary model ranks the full taxonomy. Only a primary `use_skill` result runs a second two-option model question; its probabilities divide that ambiguous class's mass between a literally named Skill and no-tool. No keyword rule changes the model output. Deterministic routing still creates every executable call and argument.

The terminal outcome and conversation projection retain complete provenance. A compact **Flow** trigger sits beside Delta and the timestamp and reports only none, tool count, failure, or offline state. Expansion shows Laya's suggested tool, a model preference score explicitly **not accuracy**, its lead over the next option, whether the suggestion matches the rule-planned tools, latency, model, proposed/final tools, routing reason, IDs, error, local/non-authority disclosures, and every separate actual execution with nested redacted I/O. `none` is the only implemented influence: the score is observed but does not cause routing. Registry schema validation, capability checks, effect policy, and confirmation remain authoritative.

The 1.0.74/code130 source correction established real file/runtime status, storage/load errors, download/load recovery and assistance opt-in only after successful loading. Expired queued requests skip inference; work already inside native inference retains session ownership until it completes. No installed-model or ready status is inferred from unsupported storage or an exception.

The pure decision interface validates typed choice distributions and returns candidates. A separate service owns app-private checkpoint files, a serialized ONNX session, loading/unloading, errors, and bounded caller waiting. The harness still owns tool validation, capability checks, confirmation policy, and execution. The adapter has no executor reference.

Settings → Models reports real model state, exact 613,050,729-byte download size, CPU provider, assistance state, and labeled intent evaluation with an itemized list of incorrect answers. Since Delta Mobile 1.0.89, assistance defaults on but only an installed verified model loads automatically after persisted settings; no download is automatic and an explicit disabled preference is respected.

Delta Mobile 1.0.89/code145 adds tool-owned deterministic matchers for `set_torch` and `list_tools`; other built-ins still use router branches. The catalog lists registered tools, not SOPs or specialist roles, and the coordinator answers those requests from verified execution summaries rather than unconstrained Nano text. ## Implemented boundary

The dedicated Laya flashlight classifier and corpus are removed. Flashlight state arguments remain deterministic like other executable arguments. Laya has no executor, argument generator, capability authority, permission grant, confirmation bypass, or right to interrupt provider chat. Probabilities remain uncalibrated. A controlled enabled/disabled case proves this non-causal boundary instead of treating score/tool correlation as selection evidence.

## Glossary and decision log

**Suggestion:** Laya's ranked label, not an action. **Model score:** selected class probability for ranking alternatives, not measured accuracy or a guarantee. **Lead:** score minus the next option's score. **Match with tool rules:** whether the suggested label appears among rule-planned calls; the internal `disposition` field preserves this structured evidence. **Registry:** execution and authorization boundary. **Unavailable:** absence of a usable result, never simulated confidence.
